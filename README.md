# LinkShort — Simple URL Shortener

A lightweight URL shortener built with **Node.js, Express.js, TypeScript, and SQLite**. It converts long URLs into short, shareable links and redirects visitors to their original destinations.

## Features

- Shorten long URLs through a REST API.
- Generate unique short codes.
- Store URL mappings persistently in SQLite.
- Reuse existing short codes when the same URL is submitted again.
- Redirect short links to their original destinations.
- Validate submitted URLs and handle unknown short codes.
- Interactive API documentation with Swagger UI.
- Simple web interface with copy-to-clipboard functionality.

## Tech Stack

- **Runtime:** Node.js
- **Backend:** Express.js
- **Language:** TypeScript
- **Database:** SQLite with `better-sqlite3`
- **API documentation:** Swagger UI
- **Frontend:** HTML, CSS, and JavaScript

## Prerequisites

Install [Node.js](https://nodejs.org/) and npm before getting started.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sammycode332/codealpha_tasks.git
cd codealpha_tasks/SimpleUrlShortner
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application runs at:

`http://localhost:3000`

Open this URL in your browser to use the web interface.

## API Documentation

Interactive Swagger documentation is available at:

`http://localhost:3000/api-docs`

### Shorten a URL

**Endpoint:** `POST /api/shorten`

Request body:

```json
{
  "url": "https://www.wikipedia.org"
}
```

Example response:

```json
{
  "code": "aa3592ee"
}
```

The generated code is an example; the actual code will be generated by the application.

### Redirect to the original URL

**Endpoint:** `GET /:code`

Example:

`http://localhost:3000/aa3592ee`

A valid code redirects the browser to its original URL. An unknown code returns a `404 Not Found` response.

## Validation and Error Handling

- `400 Bad Request` — missing, empty, or invalid URL.
- `404 Not Found` — the requested short code does not exist.
- `201 Created` — URL shortening succeeds.

## Build
